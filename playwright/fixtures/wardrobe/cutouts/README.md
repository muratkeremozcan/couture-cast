# CC-7.26 garment cutout fixtures

The 512 × 512 JPEGs contain no member data or source metadata. Each matching
`-mask.png` uses white for the target garment and black for every other pixel.
The labels follow garment outlines traced from the original photographs by hand.
The patterned shirt's hanger is background. In the cluttered scene, only the
folded white shirt is the target.

| Scene        | Source and adaptation                                                                                                                                                                                                                                                           |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Plain        | Elkagye's [white tee photograph](https://commons.wikimedia.org/wiki/File:T-shirt2.jpg), public domain. Resized and composited onto a uniform charcoal backdrop.                                                                                                                 |
| Cluttered    | NordWood Themes' [clothing flat lay](<https://commons.wikimedia.org/wiki/File:Clothing_flatlay_(Unsplash).jpg>), [CC0](https://creativecommons.org/publicdomain/zero/1.0/). Resized and edge padded to keep the accessories in frame.                                           |
| Pale-on-pale | Paulinaela's [white tee on a pale surface](https://commons.wikimedia.org/wiki/File:White-tshirt.jpg), [CC0](https://creativecommons.org/publicdomain/zero/1.0/). Resized and edge padded.                                                                                       |
| Patterned    | Ssp goldsworthy's [checkered shirt photograph](https://commons.wikimedia.org/wiki/File:Check_shirt.jpg), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Resized and composited onto a uniform blue backdrop. The adapted photograph carries the same license. |

The plain and patterned scenes exercise a confident cutout with photographic
fabric detail. The cluttered and pale-on-pale scenes exercise abstention using
the existing backgrounds in those photographs.
