# Community Beta gate signatures

Updated: 2026-11-05 - created for Story 6.13 to record the owner's sign-off.

A signature is not a launch decision.

The eight named signatures are in `_bmad-output/project-knowledge/couturecast_roadmap.md`.
Only `model` has a signing mechanism, an approval bound to the readiness payload's SHA-256 through `npm run community:screening:sign`.
Nothing recorded the other seven before this file.

A row here marked "Signed off by owner" is an owner ruling, relayed to the delivery team and written down.
It carries no cryptographic signature and no hash, and it needs no key or owner-only step.
`GATE_SIGNATURES` in `scripts/generate-community-screening-readiness.mjs` is left as it is, because it describes that payload at model sign-off.
