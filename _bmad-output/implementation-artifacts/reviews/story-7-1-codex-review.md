## Codex Security pass

- **Account isolation.** Checked live-owner gates, the native identity epoch, owner-scoped storage
  keys, and guard placement around deferred work. The old-session notice and same-account Undo
  findings affect feedback or local state integrity. The reviewed paths did not show one member
  reading or writing another member's saved looks. Existing photo-authorization and expiry checks
  must stay in place when fixing the refresh regression.
- **Probe safety.** The probe builds an unauthenticated HEAD request from build-time app
  configuration. The diff adds no member-controlled URL, payload or explicit bearer header.
  Verify the correct configured origin, cancellation and shared polling when wiring it correctly.
  Keep HTTP service failures separate from loss of connectivity.
- **Rendering and accessibility.** The new status message and action labels go through React
  text rendering. The existing static inline scripts are unchanged. No new XSS sink was found.
  The reproduced failures concern event identity, asynchronous ownership and state integrity.
- **Test integrity.** All five changed test files are new. The revision diff contains no
  edits, deletions or replacements of existing test files or assertions. The tests do not prove
  that fast transitions are spoken exactly once by real assistive technology.

## Resolution

All 13 findings (3 High, 8 Medium, 2 Low) were fixed in the CC-7.1 PR branch with focused
regression tests covering transient refresh preservation, full-capacity 8-entry Save/Remove/Undo
eviction recovery and multi-tab conflict guards, `EXPO_PUBLIC_API_BASE_URL` native connectivity
probing, per-control `useId()` notice/announcement namespacing, per-run timer and Undo epoch
isolation, live connectivity re-checks on Retry/Remove/Undo, cross-session web Home notice scoping,
composition-aware Style card reset keys, failed-remove Retry notices, inline modal offline
banners/announcements, real `HomeAddGarment` clearance measurement, guest storage honesty, Step 59
documentation accuracy, and 8 px/pt action spacing with wrapping.
